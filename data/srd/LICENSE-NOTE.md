## Data source

The JSON files in `data/srd/2014/` and `data/srd/2024/` are taken from the
[5e-bits/5e-srd-api](https://github.com/5e-bits/5e-srd-api) project
(database repo: https://github.com/5e-bits/5e-database). This project
adapts, summarises and converts that data into game content (tile ranges, short
effect lists, hand-written rule summaries). Changes are ours, not Wizards of the Coast's.
